====================================================
  REVIT MACRO TOOL — INSTALLATION
====================================================

1. Copier le fichier "launcher.exe" depuis ce dossier
   vers l'emplacement de votre choix (ex. Bureau).

2. Double-cliquer sur "launcher.exe" pour lancer l'outil.

3. Au premier démarrage, entrez votre nom d'utilisateur.
   Un identifiant unique vous sera attribué automatiquement.

====================================================
  MISES À JOUR
====================================================

Les mises à jour se font automatiquement au démarrage,
de façon silencieuse. Aucune réinstallation nécessaire.
